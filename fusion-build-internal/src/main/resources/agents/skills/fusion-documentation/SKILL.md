# Fusion documentation

The site is an AsciiDoc minisite generated by `yupiik-tools-maven-plugin` (serve with
`mvn compile yupiik-tools:serve-minisite -e` in `fusion-documentation`).

## Layout

- Hand-written topic pages: `fusion-documentation/src/main/minisite/content/fusion/*.adoc`
  (e.g. `cli.adoc`, `json.adoc`, `persistence.adoc`). `:minisite-index: N` controls the nav order/title;
  `:minisite-index-icon:` chooses the icon.
- GENERATED content: `fusion-documentation/src/main/minisite/content/_partials/generated/documentation.fusion.adoc`
  - NEVER edit by hand.

## How a module becomes browsable

The reference (config table + CLI command pages) is NOT written by hand. The annotation processor emits, at
compile time, metadata into the module jar:

- `META-INF/fusion/configuration/documentation.json` - built from `@RootConfiguration` / `@Property`.
- `META-INF/fusion/cli/cli.json` (or similar) - the `@Command` definitions.

`fusion-documentation` depends on every published module and uses
`ConfigurationDocumentationGenerator` / `CliDocumentationGenerator` / `DocumentationGenerator`
(`io.yupiik.fusion.documentation.*`) to read that metadata off the classpath and render it. There is also
`OpenRPC2Postman` / `OpenRPC2OpenAPI` / `BaseOpenRPCConverter` for the OpenRPC<->OpenAPI conversions used by
the JSON-RPC pages.

## Adding a feature or module

1. Declare user-facing annotations in `fusion-build-api`, generate wiring in `fusion-processor`
   (the metadata JSON flows from there automatically).
2. Add `fusion-documentation` as a dependency on the module so its metadata is on the docs classpath (this is
   what makes new config/CLI reference visible without hand-writing it).
3. Write a topic `.adoc` with `:minisite-index-*` front matter.
4. Run the minisite to preview. Generated partials are refreshed on build.

## Forever constraints

- Bump this when you touch `DocumentationGenerator` / the generator wiring in the docs pom (the
  `yupiik-tools-maven-plugin` executes generation during the build).
- Keep hand-written `.adoc` in sync with the generated partials; never edit `_partials/generated/**`.
