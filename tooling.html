Tooling and extras

Command line applications, testing helpers, documentation generation, templating and AI coding skills.

Overview

Beyond the core runtime, Fusion ships a set of standalone modules for building CLI applications, testing your code with the same container, documenting the metadata it generates, rendering templates and installing coding-agent skills.

Modules

  • CLI - @Command applications with @RootConfiguration parameters, subcommands and shell completion.

  • Testing - JUnit 5 extensions, TestClient, @Task hooks and programmatic bean replacement.

  • Documentation generation - convert OpenRPC/configuration/CLI metadata to Asciidoc, OpenAPI or Postman.

  • Handlebars templating - a dependency-free Handlebars engine with helpers and partials.

  • AI skills - install Fusion coding-agent skills for opencode and Claude.
