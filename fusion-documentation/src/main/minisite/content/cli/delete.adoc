== Description

Remove the Fusion AI skills previously installed for a coding agent.

== Synopsis

[source,bash]
.delete-sample
----
java -jar fusion-ai-skills-fatjar.jar \
    delete \
    --agent ...\
    --scope ...\
    --target ...
----

== Parameters

--agent::
Target coding agent: 'opencode', 'claude' or 'generic'.Provide --target to override the resolved path.

Type: `String`.

--scope::
Install scope: 'local' (current project directory) or 'global' (user home).

Type: `String`.

Default: `"local"`.

--target::
Explicit target directory holding the skills (overrides the --agent/--scope default).

Type: `String`.
