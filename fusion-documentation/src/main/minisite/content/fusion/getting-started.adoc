How to set up a project, configure the runtime and write your first Fusion applications.

== Overview

Fusion is a build-time oriented, reflectionless Java framework. You declare models and beans with plain annotations, and an annotation processor generates the wiring, codecs and configuration binding at *compile time* - only bean resolution happens at runtime. This keeps applications light and GraalVM-native friendly.

The pages below take you from an empty project to a running application:
